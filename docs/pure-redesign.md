# Pure 风格页面重构

本项目保留 Astro 6 + Tailwind CSS 和已有内容系统，按照 Astro Theme Pure 的视觉方向重构。没有直接安装 astro-pure，也没有将站点替换为官方演示站。

## 保留的内容与地址

- 保留全部文章、碎碎念正文、日期和图片引用，草稿仍不公开。2026-11-28 同步 GitHub 后为 11 篇文章、67 条碎碎念（66 条公开、1 条草稿）。
- 文章继续使用原有 slug，地址仍为 /{slug}。
- 碎碎念继续使用 /thoughts#编号，目录和分页加载保持兼容。
- 原域名、邮箱、GitHub、头像、个人介绍、友链、项目及技术栈链接。
- /posts、/thoughts、/thoughts/new、/friends、/messages、/about、/rss.xml。
- 原有 GitHub 评论、留言、点赞、在线发布 API 和 Vercel 配置，环境变量不变。

## 新的页面结构

- 居中头像与个人简介、最近文章、最近动态。
- 蓝灰色点缀、清晰的字号层级、统一留白和浅色/深色/跟随系统模式。
- 原生 dialog 搜索，支持 Ctrl/Command + K、键盘导航、搜索历史。
- 手机导航、文章目录、图片灯箱、代码块深浅主题和复制按钮。
- 移除旧页面中的壁纸、浮动装饰及手写字体引用；旧静态资源仍保留在 public 中。
- 安装到桌面的 PWA 名称改为真实博客名，并更新缓存版本。

## 日常维护

- 参考 Pure 的安全区处理及 medium-zoom 预览方式；缩放库在本站打包，不依赖外部脚本 CDN。
- 正文图片在构建时设置懒加载、异步解码，保留原图地址和作者指定的小图尺寸，同时限制容器宽度；多图行允许换行。
- 追加加载的碎碎念自动接入图片预览；加载超过 15 秒或失败时显示重试和原图入口。
- 900px 以下使用折叠导航，增大触摸按钮；手机搜索输入使用 16px 字号，弹窗高度受动态视口约束。
- Service Worker 不再拦截外部图床；本地页面网络超时后回退缓存或离线页。
- README、关于本站、页脚和项目描述统一说明设计参考关系。本站仍是独立适配，并未迁入完整 astro-pure 框架。

原图服务器的速度和可用性仍由图床决定；这次修正不会将原图变成压缩缩略图，也不会替换文章中的图片地址。

## 配置位置

- 原来的站点名称、邮箱、社交链接、项目与技术栈：src/consts.ts。
- 共用的个人信息、头像与导航：src/site.config.ts。
- 文章及碎碎念目录保持不变，原有新建脚本继续可用。
- 全站样式：src/styles/global.css。
- build 脚本改为跨平台命令，不再依赖 Unix 的 rm。

## 本地检查

运行 bun run build，再运行 bun run verify:content。
后者检查文章旧地址、全部碎碎念编号、搜索、RSS 和构建后的内部资源链接。
运行 bun dev 后访问终端打印的本地地址。

图片属性与缓存回归检查：`bun run verify:media`、`bun run verify:sw`。

2026-11-28 的检查结果：

- Astro 类型检查 0 错误、0 警告，生产构建生成 29 个页面。
- 内容检查通过：11 篇文章、66 条公开碎碎念、77 条搜索记录、66 个碎碎念锚点、671 处内部链接。
- Chromium 触摸设备模拟下检查 320、360、390、768、820、900、1440px 宽度，共 8 个页面、56 个组合，无横向溢出。
- 验证分页追加图片、连续三次 Astro 页面切换后的预览、预览中返回上一页、移动搜索、图片失败重试和 15 秒慢网提示，无未捕获脚本错误。
- 使用真实图床拍摄手机与桌面截图；网络异常测试使用受控图片响应。尚未在 iOS Safari 真机上验证。

静态预览不运行 api/ 下的 Vercel Serverless 函数，评论、点赞及发布需要原部署环境。不要在检查过程中提交测试评论或发布内容。
